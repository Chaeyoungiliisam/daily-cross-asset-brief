# 💚 Daily Cross-Asset Brief

**매일 아침 8시엔 미국, 오후 4시엔 한국 시장을 한 화면에 정리하는 데일리 마켓 브리프** 🍀

👉 **바로 보기: https://chaeyoungiliisam.github.io/daily-cross-asset-brief/**

주식·국채금리·달러·원자재·코인을 이동평균선과 매매 신호로 읽고, 거시경제 지표와 발표 일정까지 함께 봅니다.
GitHub Actions가 평일 하루 두 번 데이터를 받아 페이지를 새로 만들어서, 노트북을 켜지 않아도 늘 최신 상태예요.

---

## 💚 왜 만들었나요

시장 뉴스와 지표를 매일 챙겨 봐도 숫자를 읽는 데서 끝나기 쉬워요.
**"왜 이렇게 움직였는지"를 내 말로 설명하는 습관**을 만들기 위해, 숫자 옆에 해석과 질문을 붙인 나만의 브리프를 만들었어요.

| 기능 | 하는 일 |
|---|---|
| 🍀 해석 훈련 | 숫자마다 "그래서 무슨 의미인가"를 붙이고, 매일 데이터 기반 질문을 던져요 |
| 🍀 예측 → 채점 | 다음 거래일 코스피 방향과 근거를 적으면, 다음 날 실제 결과와 비교해 적중 여부를 보여줘요 |
| 🍀 지표 간 연결 | 미국 반도체 → 한국 반도체 → 외국인 수급 → 국채금리처럼 하루의 흐름을 한 화면에서 따라가요 |
| 🍀 투명한 데이터 | 받지 못한 데이터나 출처마다 다른 값은 숨기지 않고 표시해요 |

## 💚 어떻게 돌아가나요

```
⏰ GitHub Actions (평일 08:07 · 16:07 KST)
 │
 ├─ 1. scripts/fetch.py  ─ 데이터 수집 → data/
 │

```

|---|---|
| 미국·한국 지수, 미 국채, 달러인덱스, 원/달러, WTI·금·비트코인 선물 (1년 일봉) | Yahoo Finance |

| 오늘의 헤드라인·관련 뉴스 (최근 24시간) | 구글 뉴스 검색 |

**설계 원칙**

- 파이썬 **표준 라이브러리만** 사용해서 설치할 패키지가 없어요.
- 화면은 **HTML·CSS·JavaScript 한 파일**, 차트는 라이브러리 없이 **SVG로 직접** 그려요.
- 한 소스가 실패해도 **이전 값을 유지**하고 페이지 하단에 상태를 표시해요.
- 장이 끝나기 전에 실행돼도 **마지막으로 마감된 세션까지만** 써서 장중 값을 "마감"으로 보여주지 않아요.

## 💚 신호는 이렇게 계산해요

| 지표 | 정의 |
|---|---|
| 이동평균 | 최근 n일 종가의 단순 평균 (SMA) |
| 골든·데드크로스 | 전날과 오늘의 (단기선 − 장기선) 부호가 바뀐 날. 5/20일 = 단기, 20/60일 = 중기, 60/120일 = 장기 |
| 정배열·역배열 | 5 > 20 > 60 > 120일선 순서면 정배열(상승 추세), 정반대면 역배열(하락 추세), 섞이면 혼조 |
| 이격도 | 현재가 ÷ 20일선 × 100. 105 이상 단기 과열, 95 이하 단기 과매도 |
| 종합 점수 (±6) | 현재가 vs 20일선, 5/20·20/60·60/120일선 위아래(각 ±1) + 최근 10거래일 교차(±1) |

금리·달러·VIX는 숫자가 오를 때의 의미가 주식과 달라서 해석 문구를 따로 써요.

> 이동평균은 과거 가격의 평균이라 늦게 반응하고, 횡보장에서는 속임수 신호가 많아요. 학습용으로 봐 주세요. 💚

## 💚 만든 과정

1. **구성 설계** — 업계에서 흔히 쓰는 모닝 브리프 형식(미국 지수 → 글로벌 → 업종 → 금리·환율·원자재 → 국내 수급)을 참고해 화면을 정했어요.
2. **바이브 코딩** — Claude에게 보고 싶은 지표, 이동평균선, 화면 구성을 말로 지시하며 만들었어요.
3. **수치 검증** — 16개 시계열의 개수·합계를 원본과 대조하고 지수 종가를 마감 시황 기사와 맞춰 봤어요. 이 과정에서 기사 본문의 코스닥 수치 오류와 원/달러 역외·서울 종가 차이를 찾았어요.
4. **자동화** — GitHub Actions로 평일 하루 두 번 자동 갱신되게 만들었어요.
5. **막힌 소스 대체** — 첫 실행에서 국고채(Investing.com)·매매동향·FRED가 GitHub 서버에서 막혀, 한국은행 ECOS·네이버 증권 API·경제 캘린더 실제치로 바꿨어요. 수집 시간도 5분에서 1분 이내로 줄였어요.

코드는 Claude(Anthropic)가 작성했고, 저는 요구사항 정의, 디자인 피드백, 수치 검증을 맡았어요. 🍀

```
daily-cross-asset-brief/
├─ .github/workflows/update.yml   자동 실행 일정

└─ docs/index.html                완성된 페이지 → GitHub Pages
```

내 컴퓨터에서 실행:

```bash
python scripts/fetch.py   # 데이터 받기
python scripts/build.py   # docs/index.html 만들기
```

**선택: AI 뉴스 요약** — 저장소 Settings → Secrets and variables → Actions에 `ANTHROPIC_API_KEY`를 한 번 넣어 두면,
