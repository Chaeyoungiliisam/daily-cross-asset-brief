                신호 해석

                최근 발생한 신호

                  신호 읽는 법

                  골든크로스 · 데드크로스
                  짧은 이동평균선이 긴 선을 아래에서 위로 뚫으면 골든크로스(매수 신호), 위에서 아래로 뚫으면 데드크로스(매도 신호)로 봅니다. 5/20일선은 단기, 20/60일선은 중기, 60/120일선은 장기 추세를 말합니다.
                  정배열 · 역배열
                  위에서부터 5 > 20 > 60 > 120일선 순으로 놓이면 정배열입니다. 최근 가격일수록 비싸다는 뜻이라 상승 추세로 읽습니다. 순서가 정반대면 역배열(하락 추세), 섞여 있으면 혼조(전환 구간)입니다.
                  이격도
                  현재가 ÷ 20일선 × 100. 105 이상은 단기 과열, 95 이하는 단기 과매도로 보고 되돌림 가능성을 점검합니다.
                  주의할 점
                  이동평균은 과거 가격의 평균이라 늘 늦게 반응합니다. 횡보장에서는 교차가 짧은 간격으로 반복되는 속임수 신호가 많습니다(예: 나스닥 5/20일선은 9월에 세 번 교차). 금리·환율·VIX는 숫자가 오르는 의미가 주식과 다릅니다.

                  물가

                  고용 · 성장 · 정책금리

                          표 읽는 법

                          금리는 bp(0.01%p) 변동, 나머지는 등락률입니다. 이격도는 현재가 ÷ 20일선 × 100입니다. 행을 누르면 차트 탭에서 열립니다. 미국 지표는 10/12 마감, 한국 지표와 국고채는 10/13 마감, 원/달러는 24시간 역외 시세입니다.

                          01나의 문제의식

                          매일 시장 뉴스와 지표를 챙겨 봐도 숫자를 읽는 데서 끝나고 "왜 이렇게 움직였는지"를 제 말로 설명하는 훈련은 되지 않았습니다. 금리·환율·유가·주가가 서로 어떻게 연결되는지 감이 없으니 같은 자료를 봐도 남는 것이 적었습니다.

                          증권사 앱에는 데이터가 넘치지만 해석은 각자의 몫이고, 내가 세운 가설이 맞았는지 되돌아볼 장치도 없습니다. 그래서 매일 같은 틀로 데이터를 보고, 질문에 답하고, 예측을 기록해 다음 날 채점하는 나만의 루틴 도구를 만들었습니다.

                          +이 대시보드만의 차별점

                          • 해석 훈련: 숫자마다 "그래서 무슨 의미인가"를 붙이고, 매일 훈련 질문을 던집니다.
                          • 예측 → 채점 루프: 다음 날 방향과 근거를 적고 이튿날 결과와 비교합니다.
                          • 지표 간 연결: 미국 반도체 → 한국 반도체 → 외국인 수급 → 국채금리처럼 하루의 흐름을 한 화면에서 따라갑니다.
                          • 검증 과정 공개: 출처마다 수치가 다른 경우를 그대로 표시합니다.

                          02내가 만든 과정

                          1. 구성 설계업계에서 흔히 쓰는 모닝 브리프 형식(미국 지수→글로벌→업종→금리·환율·원자재→국내 수급)을 참고해 화면 구성을 정했습니다.
                          2. 요구사항 지시Claude에게 보고 싶은 지표, 이동평균선, 화면 구성을 말로 지시했습니다(바이브 코딩).
                          3. 데이터 경로 확보작업 환경에서 금융 사이트가 막혀 있어, 내 컴퓨터의 브라우저로 Yahoo Finance·FRED·Investing.com 데이터를 받아오는 방식으로 바꿨습니다.
                          4. 결과 검증16개 시계열의 개수와 합계를 원본과 대조했고, 지수 종가를 뉴스 마감 시황과 맞춰 봤습니다. 이 과정에서 기사 본문의 코스닥 수치 오류와 원/달러 역외·서울 종가 차이를 찾았습니다.
                          5. 피드백 반영 (v2)3열 탭 레이아웃, 그린 테마, 골든·데드크로스 신호, 08시·16시 브리프, 국고채 이동평균, 거시지표 탭을 추가했습니다.
                          6. 자동화GitHub Actions가 평일 08:00·16:00(한국시간)에 데이터를 받아 이동평균·신호·브리프 문장을 계산하고 GitHub Pages에 다시 배포합니다. 노트북을 켜지 않아도 갱신됩니다.
                          7. 다음 단계예측 적중률 누적 기록, 뉴스 요약 자동화(Claude API).

                          03코드는 무엇을 바탕으로 했나

                          • 화면: 프레임워크 없이 HTML·CSS·JavaScript 한 파일. 차트는 라이브러리 없이 SVG로 직접 그립니다.
                          • 자동화: GitHub Actions(정해진 시간에 코드를 실행하는 무료 서버)와 GitHub Pages(무료 웹 호스팅).
                          • 계산: Python 표준 라이브러리만 사용. 이동평균은 단순이동평균(SMA, n일 종가의 산술평균)이고, 교차는 전날과 오늘의 (단기선 − 장기선) 부호가 바뀌는 날로 찾습니다.
                          • 신호 점수: 현재가와 20일선, 5/20·20/60·60/120일선의 위아래 관계(각 ±1)에 최근 10거래일 교차(±1)를 더한 교육용 점수입니다.
                          • 작성: 코드는 Claude(Anthropic)가 작성했고, 저는 요구사항 정의·디자인 피드백·수치 검증을 맡았습니다.

                          04데이터 출처와 가져오는 방식

                          • Yahoo Finance 일봉 (1년)미국·한국 지수, 미 국채, 달러인덱스, 원/달러, WTI·금·비트코인 선물, VIX. 차트 API(JSON)를 호출
                          • Investing.com 일봉국고채 3년·10년. 과거 데이터 API(JSON)를 호출 · 실패하면 이전 값 유지
                          • FRED (세인트루이스 연은)CPI, 근원 CPI, PCE, PPI, 실업률, 비농업 고용, GDP, 연준 목표금리. CSV를 받아 전년비 계산
                          • 네이버 금융코스피·코스닥 투자자별 순매수(억 원). 표를 읽어 옴
                          • 직접 입력 (config/manual.json)한국 소비자물가, 한은 기준금리, 경제 일정, 시장 해석. 금통위·발표가 있을 때 고칩니다
                          가격: Yahoo Finance · 국고채: 한국은행 ECOS · 거시: FRED·Trading Economics · 수급: 네이버 증권 · 일정: Trading Economics · 기준금리: 한국은행 · 뉴스: 구글 뉴스
